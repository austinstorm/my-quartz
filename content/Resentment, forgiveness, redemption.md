> Resentment is continuing a behavior today that’s intended to make a hurt that happened yesterday better….  Forgiveness is stopping behavior today that’s intended to make a hurt that happened yesterday better….  Reality is an accepting that what happened yesterday cannot be changed with any behavior today and remembering that today is going to be a yesterday…. Redemption is behaving today that makes it a yesterday that if repeated makes a today better
